📖 Style Studio Help

Visual OBS Theme Generator allows you to build, test, and export customized themes based on the Yami theme architecture.

  • Import: Load an existing .ovt theme file or from clipboard.
  • Export: Download your updated theme file or save to clipboard.

  • Directory: C:\Program Files\obs-studio\data\obs-studio\themes


    • A property isn't working? We offer a handfull of properties, but some cannot be applied to certain elements.
