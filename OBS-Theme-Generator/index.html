📖 Style Studio Help

Visual OBS Theme Generator allows you to build, test, and export customized themes based on the Yami theme architecture.

  • Inspect: Click any dock, header, or preview frame in the workspace to customize its theme variables.
  • Import: Load an existing .obt or .ovt theme file to read its @OBSThemeVars and edit them live.
  • Export: Download your updated theme configuration file ready to drop into OBS Studio.

  • Directory: C:\Program Files\obs-studio\data\obs-studio\themes
